# GBF Bookmark
Forked from [gbf-web-bookmark-plugin](https://github.com/MoShuangYanQin/gbf-web-bookmark-plugin) by [MoShuangYanQin](https://github.com/MoShuangYanQin).

This fork includes a few modifications for personal use.

## Changes since v7.1.8 fork
- Fix randomly occurring panel sizing and positioning problem.
- Remove the call up animation.
- Add pin button for locking panel position.
- Add a shortcut enable status when setting label shortcuts.
- Add custom tab names support.
- Suppress the original actions for keyboard and mouse shortcut(e.g. The right-click menu will not be called when using mouse right click as a shortcut key).
